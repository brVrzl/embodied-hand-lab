# π0.5/RH56 training

## English

This is the project-specific OpenPI adapter for the fixed task prompt
`Pick up the bottle and place it on the cardboard box.` It initializes
`pi05_base` with the official JAX LoRA path. The native action boundary is
12-D arm plus six active RH56 channels; OpenPI's internal projection is handled
by the adapter without inventing independent RH56 joints. Source force is
preserved but not used by this first baseline.

The current config and runtime are:

- `configs/training/pi05/physical_bottle.yaml`;
- `configs/training/pi05/openpi.lock.json`;
- `training/pi05/openpi_adapter.py`;
- `training/pi05/scripts/openpi_runner.py`;
- `training/pi05/scripts/train_weekend.sh`.

Check the pinned runtime, then use the training-only supervisor:

```bash
training/pi05/scripts/check_openpi.sh --require-image
training/pi05/scripts/train_weekend.sh start
training/pi05/scripts/status.sh
training/pi05/scripts/train_weekend.sh resume
```

The supervisor uses local logs/checkpoints and resume without overwrite. It
does not connect to JAKA, RH56, Quest, or cameras.
