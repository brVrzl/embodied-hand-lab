# Vision interface

## English

This package owns the RealSense adapter and saved RGB-D processing contracts.
Device identity must be explicit. The stream checker and RGB-D processor are
current tools; neither automatically connects to an arbitrary camera.

## 中文

本 package 负责 RealSense adapter 和保存的 RGB-D processing contract。设备 identity 必须显式指定。stream
checker 和 RGB-D processor 是当前工具；二者都不会自动连接任意 camera。
