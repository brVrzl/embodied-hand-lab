# Selected Papers

This folder contains the 10 papers most directly useful for the current JAKA mini2 + Inspire RH56 project:

- DexUMI: human hand as dexterous UMI.
- DEXOP: perioperation / passive exoskeleton data collection.
- TypeTele: manipulation-type-guided dexterous teleoperation.
- RwoR: human-hand demonstrations converted to robot gripper demonstrations.
- UMI: in-the-wild robot teaching via handheld gripper.
- ACE: low-cost cross-platform visual exoskeleton teleoperation.
- Sim-and-Real Co-Training: recipe for mixing real and sim manipulation data.
- Data Scaling Laws: data composition and scaling for imitation learning.
- DexMimicGen: simulation data generation from few demos.
- FAIL-Detect: failure detection for imitation learning policies.

The full downloaded PDF set is in `../papers/dexterous_manipulation_2024_2026/`.
