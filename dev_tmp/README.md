# Development records / 开发记录

This directory contains recoverable working records, validation logs, dated
reports, and measurement requests. It is not an operating authority and must
not be used to infer current capability, physical validation, or safety
permission. Current instructions live under `docs/` and the repository root
`AGENTS.md`.

本目录保存可恢复的开发记录、验证日志、阶段报告和测量请求，不是项目操作依据，不能
用来推断当前能力、真机验证结论或安全授权。当前说明以 `docs/` 和仓库根目录
`AGENTS.md` 为准。

## Contents / 内容

- [`maintenance/`](maintenance/) — repository cleanup and integration records.
  仓库清理与集成过程记录。
- [`digital_twin/`](digital_twin/) — reconstruction, calibration, and
  measurement records. 数字孪生重建、标定和测量记录。

Records are preserved as evidence; do not edit them to make them match later
behavior. Update the relevant current page under `docs/` when a decision or
status becomes authoritative.

记录作为证据保留，不要为了匹配后续行为而改写；当结论或状态成为当前权威时，更新
`docs/` 下对应的当前页面。
